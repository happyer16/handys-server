## 2. Stage & RARRA

| 항목 | 값 |
|------|-----|
| Stage | Traction (Pre-PMF) / Transition / Growth |
| Bottleneck | Retention / Activation / Referral / Revenue / Acquisition |
| Aha Moment | |
| North Star / KR | SMART Result. Action 금지 |

**진단 순서:** Retention → Activation → Referral → Revenue → Acquisition

Acquisition을 병목으로 쓰려면 위 네 칸이 이미 검증됐다는 근거가 있어야 한다.

허영 지표(가입자, PV, 설치 수)로 North Star를 쓰지 않는다.
