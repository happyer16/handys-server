# RARRA — 참고

출처: RARRA의 중요성 (Problem Solver Perspective)

## 왜 RARRA인가

시장 포화·CAC 상승 시대에 Acquisition 중심 AARRR는 **밑 빠진 독에 물 붓기**가 되기 쉽다.

- 모바일: 설치 후 3일 내 ~77% 이탈, 90일 후 ~95% 이탈 (자료 기준)
- Retention 없는 획득 증가는 **허영 지표(Vanity Metrics)** 일 수 있음
- PS 실력 = "얼마나 데려오는가"가 아니라 **"얼마나 남기는가"**

## AARRR vs RARRA

| | AARRR | RARRA |
|--|-------|-------|
| 순서 | Acquisition → Activation → Retention → Referral → Revenue | **Retention → Activation → Referral → Revenue → Acquisition** |
| 핵심 질문 | 어떻게 더 많이 데려올까? | 어떻게 계속 남게 할까? |
| 성장 방식 | Marketing-led | **Product-led** |
| 우선 지표 | 가입자, CAC, 방문자 | Retention rate, Active users |
| 역할 | 요구사항 수동 실행 | 데이터로 문제 진단·해결 주도 |

## RARRA 5단계 체크

1. **Retention** — 다시 찾게 만드는 핵심 가치를 주는가?
2. **Activation** — 첫 방문에서 가치를 깨닫는 Aha Moment를 겪는가?
3. **Referral** — 만족한 사용자가 자발적으로 추천하는가?
4. **Revenue** — 기꺼이 지불할 만큼의 가치인가?
5. **Acquisition** — 검증된 유지력 위에서 효율적으로 신규를 부르는가?

## 사례 레슨 (요약)

- **Hitlist:** 유입 과대 → 광고 중단, Retention UX·Activation(거래) 집중 → 1주 유지율·결제 비율 급개선. 교훈: 가입자 수에 속지 말고 유지율 먼저.
- **Blinkit:** 온보딩/Activation 마찰 제거로 Retention 개선. 마케팅 비용↑보다 경험 최적화가 Activation→Retention 연결.

## 실전 PS 가이드

### 1. 유지를 North Star로

- 팀 공통 북극성으로 Retention Rate류 지표
- 단기 수익/유입 일희일비 금지, 반복 사용 주기 관찰
- 예: "이번 분기 30일 유지율 25% → 35%"
- 유지율은 한 부서 KPI가 아님 — 사일로 해체

### 2. 교차기능 Retention TF

마케팅 + 제품(기획/개발/디자인) + 데이터. 이탈 원인 다각도, 피드백 실시간 공유.

### 3. 생애주기 매핑·개인화

일괄 대하지 말고 적시·적절 액션:

| 세그먼트 | 기준 예 | 목표 | 액션 예 |
|----------|---------|------|---------|
| 신규 | 가입 ≤7일 | 온보딩·Aha | 튜토리얼, 웰컴 혜택 |
| 활성/충성 (RFM) | 최근 접속·빈도·LTV 상위 | VIP·Referral | VIP 혜택, 추천 유도 |
| At-risk | 미접속 ~14일 | 습관 붕괴 방지 | 맞춤 푸시·한정 혜택 |
| 완전 이탈 | ≥30일 미접속 | (복구 CAC 높음) | 재활성 메일/광고 — 우선순위 낮을 수 있음 |

## prd-harness 적용 규칙

- 기획 제안 시 **항상 RARRA 병목 한 줄**을 밝힌다.
- Acquisition 솔루션을 먼저 내면 안 된다. Retention/Activation 미검증이면 되돌린다.
- "기능 추가"가 Retention을 어떻게 바꾸는지 연결되지 않으면 기각하거나 실험으로 격하한다.
